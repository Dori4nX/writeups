# Metodologías

Esta sección está destinada a recopilar procedimientos, listas de comprobación y notas técnicas reutilizables durante la resolución de laboratorios. El contenido se ampliará de forma progresiva a medida que las técnicas se practiquen y documenten.

> **Uso ético:** estas metodologías se aplican exclusivamente en laboratorios, CTF, máquinas propias o sistemas con autorización explícita. No deben utilizarse contra sistemas ajenos sin permiso.

## Enumeración

**Contenido en desarrollo.**

Este apartado recogerá un proceso ordenado para identificar servicios, tecnologías y posibles superficies de ataque.
